# Rekvero — три направления логотипа

1. **Маршрут** — монограмма R с акцентной диагональю. Основной рекомендуемый вариант; установлен в текущем интерфейсе и favicon.
2. **Фокус** — четыре опоры и центр внимания. Акцент на проверке данных и выделении главного.
3. **Связь** — два соединённых контура. Акцент на объединении рекламных и бизнес-данных.

Векторные SVG и прозрачные PNG лежат рядом. Суффикс `-dark` — светлый логотип для тёмного фона. `mark-*` — отдельные знаки. `preview.html` и `preview.png` — лист сравнения; `social-preview.svg` — исходник карточки для ссылок. Словесная часть остаётся редактируемым SVG-текстом Arial/Helvetica; для печати перед передачей в типографию перевести её в кривые выбранным шрифтом.

Палитра: `#142725` графитовый зелёный, `#C39A5D` шампань, `#F4F2EC` тёплый белый. Для favicon используется монограмма на контрастном фоне. Формы созданы как исходные SVG, без генерации растровых логотипов; масштабируются без потери качества.

Иллюстрация ноутбука отдельно обновлена встроенным imagegen: запрос на точечную замену AdPilot → Rekvero и знака A → R при сохранении композиции, освещения, фона и графиков. Новый файл — `designe 1.0/public/reference/rekvero-hero-scene.png`; прежний исходник сохранён.

Проверка доступности товарного знака и домена не проводилась. Эти варианты — дизайн-концепции, а не подтверждение исключительных прав.
