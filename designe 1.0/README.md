# Rekvero — designe 1.0

Локальный кандидат публичного сайта, проверен 18 октября 2026 года. Изменения ограничены этой папкой. Основные frontend/ и backend/ не заменены.

Главная: http://127.0.0.1:3120/ — первый экран, возможности, порядок работы, тарифы. Демо удалено из публичного пути пользователя; прежние /demo/* ведут в /workspace. Сохранённые файлы старого прототипа и его отчёты не являются публичными экранами или доказательством текущей готовности.

Рекомендуемые цены: Контроль — 1 990 ₽/мес. за 1 рекламный аккаунт; Бизнес — 4 990 ₽ до 5; Агентство — 9 990 ₽ до 15. Это предложение, добавленное в локальный интерфейс. Оплата и серверные права по тарифам ещё не подключены.

## Локальный запуск

Из этой папки: `npm ci`, `npm run build`, затем `npm run start -- --hostname 127.0.0.1 --port 3120`.
На текущем компьютере node_modules связан с зависимостями основного frontend. В архив ссылка не входит; после переноса используйте npm ci. Секреты в архив не входят.

Настройки процесса Next.js:

- ADPILOT_API_URL — origin существующего backend без пути; HTTPS, кроме локального loopback. Код добавляет /api/v1.
- ADPILOT_SESSION_COOKIE — имя серверной cookie, по умолчанию session. Токен не передаётся через env, query или localStorage.
- NEXT_PUBLIC_SITE_URL — подтверждённый публичный HTTPS origin при сборке. Пока не задан, индексация закрыта.
- NEXT_PUBLIC_YM_ID — необязательный согласованный счётчик. Загружается после согласия; рабочий экран исключён, Webvisor/clickmap отключены.

Вход /login использует существующий серверный Яндекс ID OAuth. /signup ведёт к этому входу. Создание аккаунта доступно только после получения утверждённых документов точной редакции от backend. Если API/OAuth не настроены, интерфейс показывает ошибку и не имитирует создание аккаунта. Доступ к Директу/Метрике подключается отдельно от входа.

/workspace — срез чтения существующих /me, today и recommendations. Деньги форматируются из Decimal-строк; нет подстановки вымышленных метрик при ошибках. Оплата, автоматизация рекламы и полный цикл выполнения рекомендаций не реализованы этим изменением.

## Проверки этой версии

`npm run lint`, `npm run build`, `npm run test:pilot`, `node scripts/check-auth-proxy.mjs`, `npm run test:headers`.
Браузерная проверка главной: `node artifacts/tools/check-public-launch.mjs` при работающем preview на 3120. Требуется Playwright и Edge; в локальном инструменте указан путь установленного bundled runtime. Для отдельного headers-прогона заданы NODE_PATH, BROWSER_PATH и REQUIRE_BROWSER=1.

Исходный дизайн — растровые обрезки. Шрифты, отдельные фотослои и мобильные оригиналы не предоставлены, поэтому буквальное совпадение всех пикселей не заявляется. Фотография ноутбука — ранее подготовленная иллюстрация интерфейса, её цифры не являются результатами клиентов. Новые цены и тексты намеренно отличаются от прототипа по запросу владельца.
