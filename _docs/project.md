# ai-direct — бизнес-контекст

Источник: `docs/PRD.md` v1.0 (согласован 2026-09-29, обновлён под решения P0 2026-10-02). Выжимка для спек; при расхождении прав PRD, по объёму версий — канон `docs/VERSION_SCOPE.md`.

## Что это
Платформа контроля рекламных расходов с AI-аналитиком. Покупают не AI, а контроль денег, поиск неэффективных расходов, прозрачность подрядчиков и понятные действия.
Оффер: «Подключите Яндекс.Директ за 2 минуты — покажем, где рекламный бюджет расходуется неэффективно».

## Кто клиент
МСБ: собственники, маркетологи, агентства. Любая ниша, канал — Яндекс.Директ. Боль: непрозрачные расходы, незамеченный неэффективный расход, сложные кабинеты, нет понятных советов.

## Четыре сущности продукта
Расход с признаками неэффективности ≈ N ₽ (оценка, одна сумма учитывается один раз) → Почему (причина + данные) → Можно сэкономить ≈ (оценка с формулой и уверенностью) → Что сделать (конкретное действие). Проходят через дашборд, аудит, Telegram-дайджест, рекомендации, историю решений.

## Принятые решения (не противоречить в спеках)
- Замкнутый цикл: данные → rule engine → AI-объяснение → доказательства → рекомендация → одобрение человека → изменение → проверка через 7 дней.
- Интерфейс: сначала ответ, потом доказательства, потом инструменты. Не копируем кабинеты для профессионалов.
- Главный KPI: эффект в деньгах. v1.0 — «Сэкономлено ≈ N ₽» = конверсии_после × max(CPA_до − CPA_после, 0), если конверсии не упали (`high_cpa_measure@2`); только по выполненным рекомендациям, `estimated`, сравнение 7 дней до и после без контрольной группы. Не «возвращено», не «заработано», не «потеряно».
- Принципы AI: никаких выдуманных данных; вывод = источник + цифры + уверенность; факты важнее красивого ответа; никаких изменений в кабинете без одобрения (число одобрений — по уровню риска действия); каждый вывод воспроизводим (цифра → источник → период → снимок → версия правила → рекомендация).
- Числа считает детерминированный код, LLM только объясняет.
- Честный биллинг, без тёмных паттернов (PRD §7).

## Объём v1.0 (канон — `docs/VERSION_SCOPE.md`)
Входит: Директ + Метрика (OAuth — только подключение данных), ежедневный аудит, рекомендации с блоком «Почему так решил», исполнение через Direct API с предпросмотром, одобрением по уровню риска и откатом, ручное выполнение со сверкой, «что изменилось за сутки», история решений с проверкой через 7 дней, свежесть данных и здоровье интеграций, несколько кабинетов в workspace, агентства с ролями org + workspace, «Спросить AI» (только чтение), Telegram без названий кампаний, бесплатный первый аудит + подписка. Вход — по номеру телефона и SMS-коду (юридический HOLD, `docs/LEGAL.md`).
v1.1: Root Cause Engine, Business Memory, Policy Center, Action Request из «Спросить AI» и др. v2.0: автоматизация по заранее одобренным правилам (режимы безопасности), CRM, VK Реклама.
Срок: исходные «3 недели MVP» пересматриваются (PRD §10 №14).
