# ai-direct — бизнес-контекст

Источник: `docs/PRD.md` v1.0 (согласован 2026-09-29). Выжимка для спек; при расхождении прав PRD.

## Что это
Платформа контроля рекламных расходов с AI-аналитиком. Покупают не AI, а контроль денег, поиск потерь, прозрачность подрядчиков и понятные действия.
Оффер: «Подключите Яндекс.Директ за 2 минуты и узнайте, где теряются деньги в рекламе».

## Кто клиент
МСБ: собственники, маркетологи, агентства. Любая ниша, канал — Яндекс.Директ. Боль: непрозрачные расходы, незамеченные потери, сложные кабинеты, нет понятных советов.

## Четыре сущности продукта
Потеряно (₽ по источникам) → Почему (причина + данные) → Можно вернуть (оценка с формулой и уверенностью) → Что сделать (конкретное действие). Проходят через дашборд, аудит, Telegram-дайджест, рекомендации, историю решений.

## Принятые решения (не противоречить в спеках)
- Замкнутый цикл: данные → rule engine → AI-объяснение → доказательства → рекомендация → одобрение человека → изменение → проверка через 7 дней.
- Интерфейс: сначала ответ, потом доказательства, потом инструменты. Не копируем кабинеты для профессионалов.
- Главный KPI: эффект в деньгах. MVP — «Сэкономлено ≈ N ₽» (расход за 7 дней до минус после, если конверсии не упали; только по выполненным рекомендациям, помечено `estimated`). Не «возвращено» и не «заработано».
- Принципы AI: никаких выдуманных данных; вывод = источник + цифры + уверенность; факты важнее красивого ответа; никаких изменений в кабинете без одобрения; каждый вывод воспроизводим (цифра → источник → период → снимок → версия правила → рекомендация).
- Числа считает детерминированный код, LLM только объясняет.
- Честный биллинг, без тёмных паттернов (PRD §7).

## MVP (3 недели)
Входит: Директ + Метрика (OAuth), ежедневный аудит потерь в ₽, рекомендации с блоком «Почему так решил» (выполнение вручную), «что изменилось за сутки», история решений с проверкой через 7 дней, свежесть данных и здоровье интеграций, Telegram (утренний дайджест + недельный отчёт), дашборд, бесплатный первый аудит + подписка.
Не входит (v2.0): AI-чат, автоприменение с предпросмотром и откатом, режимы безопасности, CRM, VK Реклама.
