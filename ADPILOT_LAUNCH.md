# AdPilot: основной сайт для запуска

Основной frontend: **`designe 1.0/`**. Дизайн: присланный владельцем `ad.png`, светлый интерфейс с фиолетовыми/голубыми акцентами, светлая боковая навигация и главная с ноутбуком.

Для hosting/deployment установите Root Directory в `designe 1.0`. Каталог `frontend/` сохранён как legacy и этим коммитом не изменяется. Коммит дизайна сам по себе не публикует сайт.

```powershell
cd 'designe 1.0'
npm ci
npm run lint
npm run test:model
npm run test:pilot
node scripts/check-workspace-proxy.mjs
node --experimental-strip-types scripts/check-chart-geometry.mjs
npm run build
npm run start -- --hostname 127.0.0.1 --port 3120
```

Нужны Node.js 22.6+ и настройки backend-origin через `REKVERO_API_URL` (совместимый alias `ADPILOT_API_URL`). Приложение не содержит серверных секретов. `REKVERO_APP_ORIGIN` задаёт публичный origin. `NEXT_PUBLIC_SITE_URL` задаётся только после подтверждения публичного HTTPS-домена; до этого индексация закрыта.

Главная: `/`. Интерактивная демонстрация: `/demo`, все 12 разделов доступны в боковом меню. Рабочий кабинет: `/workspace`; он требует совместимый отдельно настроенный backend и сессию. Демо явно маркирует модельные показатели; реальные данные не подменяются демонстрационными.

Сохраняются ограничения: нет подключённой оплаты, автоматических рекламных изменений и гарантированной экономии; источники VK/Telegram/Авито — в разработке. Дневной ряд и измеренный эффект появятся в рабочем интерфейсе после реализации соответствующих API. Названия разделов и полное меню демо не доказывают наличие всех production-возможностей.

Этот коммит включает frontend и его проверки. Накопленные backend-изменения, другая работа в `frontend/`, локальные БД, `.env`, временные артефакты и ключи не включены. Для production нужны отдельная готовность backend, домен/HTTPS, SMTP/OAuth, утверждённые документы, мониторинг и проверенное восстановление БД.
