# Объём версий AdPilot — канон

> Принято владельцем продукта 2026-10-02 (решения P0: D1–D18). Этот файл — единственный источник истины о том, **что входит в какую версию**. Другие документы описывают, *как* это устроено, и на объём ссылаются сюда.

Правила:
- Расхождение по объёму между документами → прав этот файл; остальные исправляются.
- Новая функция попадает в версию только строкой здесь. Нет строки — функция не запланирована.
- Метки в тексте документов: **[v1.0]**, **[v1.1]**, **[v2.0]**.

## 6. Открытые вопросы по объёму

1. **Срок v1.0.** Объём v1.0 с решениями P0 не помещается в исходные «3 недели» (PRD §9) — план и разбивку на релизы нужно пересмотреть (PRD §10 №14).
2. **Запуск регистрации по SMS** — HOLD до заключения юриста по 149-ФЗ (LEGAL.md, PRD §10 №13). Если порядок не подтвердится — запасной вариант D2: вход через Яндекс ID (уже в коде); перенос его в v1.0 — решение владельца.
3. **Неэффективные часы и регионы** (PRD §4, правила аудита): правило есть в списке кандидатов v1.0, но D9 упоминает измерения «регион и час — когда появятся». Решить, входит ли правило в v1.0.
4. **Идеи без версии** (PRD §6): рейтинг здоровья рекламы, AI-контроль подрядчика, настройка порогов готовых правил — ни в одну версию не включены.
5. **Напоминание о списании без email** (PRD §10 №15): email стал необязательным, канал для пользователя без email и Telegram не решён.
