## Что доступно людям

Сейчас можно приглашать людей тестировать публичные страницы и демонстрационный кабинет. Демонстрационные цифры остаются синтетическими. Email-регистрация на сервере отключена (`email_enabled: false`); создание аккаунта в форме недоступно. Публикация кода сама не включает почту, OAuth, оплату или рекламные операции.

Для пилота с настоящими аккаунтами следующий этап: утвердить документы и контакты оператора, настроить отправку почты и OAuth, затем пройти внешний сценарий регистрации → подтверждения → подключения Direct/Метрики → синхронизации → рекомендаций двумя пользователями. Старую привязку Метрики потребуется подтвердить повторно. Проверка реальных провайдеров, платежей и восстановление действующей облачной базы в этот выпуск не входили.

Текущий бесплатный Render может засыпать. По проверенной конфигурации бесплатная PostgreSQL истекает 19.11.2026; до использования настоящих данных нужно решить вопрос постоянного хранения и размещения. Платные ресурсы и настройки провайдеров в этом выпуске не менялись.

После runtime commit добавляется только этот протокол и его доказательства с `[skip ci] [skip render]`; исходники приложения остаются теми же. Такой документальный коммит не обозначает новый запуск приложения.
