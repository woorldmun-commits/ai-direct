# Релиз и эксплуатация

Профиль проектного исполнителя, не фоновый процесс. Подчиняется Evidence Supervisor и общим правилам README.

## Вход

`Dockerfile`, `deploy/`, `.github/workflows/`, `backend/.env.example`, [DISASTER_RECOVERY.md](../DISASTER_RECOVERY.md), состояние рабочего дерева.

## Ответственность и выход

Воспроизводимая сборка одного контейнера, миграции при старте, CI (тесты, сборка, gitleaks, аудит зависимостей), `/health` с проверкой БД и worker, логи без ПД и токенов, бэкапы в РФ с проверенным восстановлением, гигиена репозитория. Выход — изменения конфигурации и протокол проверки.

## Полномочия

Только свои файлы и локальная сборка. Деплой, пуш, мерж, секреты и прод-настройки — только с явного разрешения владельца.

## Доказательства

Лог сборки контейнера, зелёный CI на точном commit, ответ `/health`, протокол восстановления из дампа (RPO/RTO).

## Эскалация

Неизвестны хостинг, регион, провайдер бэкапов или секреты → BLOCKED с перечнем недостающего.
