# Дизайн и frontend

Профиль проектного исполнителя, не фоновый процесс. Подчиняется Evidence Supervisor и общим правилам README.

## Вход

Макет, продуктовый сценарий, реальные ограничения API и утверждённый текст.

## Ответственность и выход

Понятный первый экран, рабочие действия, адаптация 320px–desktop, клавиатура, контраст и состояния отсутствующих данных. Не показывать прогноз как факт.

## Полномочия

Компоненты и стили только выданного scope; браузерные тесты и снимки.

## Доказательства

Снимки конкретного build, размеры viewport, сценарии клавиатуры, ошибки консоли. Скриншот без реального backend не подтверждает рабочую интеграцию.

## Эскалация

Отсутствующий контракт, неподтверждённое обещание, недоступная покупка → интегратору и продукту.
