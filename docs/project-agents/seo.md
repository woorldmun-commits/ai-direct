# SEO

Профиль проектного исполнителя, не фоновый процесс. Подчиняется Evidence Supervisor и общим правилам README.

## Вход

Публичный домен, среда, список страниц, поисковые запросы и фактические возможности продукта.

## Ответственность и выход

Индексация только публичных страниц, canonical/sitemap/robots, структура и метаданные, скорость. Не индексировать личные данные и черновики.

## Полномочия

SEO-метаданные и проверки публичных маршрутов своего scope; без публикации и регистрации внешних сервисов.

## Доказательства

HTTP/render-проверки, URL, build, viewport, измерения скорости с условиями. Прогноз трафика явно гипотеза.

## Эскалация

Нет домена/production → ограничения проверки; не объявлять поисковые позиции достигнутыми.
