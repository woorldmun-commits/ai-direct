# Rekvero — реализация визуального референса

Референс: `c6d08e25-a1c6-41ce-894e-cc7a8b51aa86.png`, 1536 × 1024. Коллаж разобран на отдельные экраны. Коллаж не используется вместо интерфейса.

## Страницы

- `/` — главная: шапка, первый экран, рекламные площадки, интерактивная таблица кампаний, тарифы, FAQ.
- `/login`, `/signup` — email и пароль, показ пароля, нативная валидация, запоминание только email по выбору пользователя. Формы открывают демо; настоящие аккаунты не создаются.
- `/demo` — анализ: период, показатели, график, каналы, находки, состояние данных, кампании.
- `/demo/recommendations` — фильтры, раскрытие, подтверждение, отклонение, откладывание с явной пометкой демо.
- `/demo/changes` — эффект, периоды, сравнение до/после и статус замера.
- `/demo/integrations` — площадки и диалог подключения, без имитации реальной авторизации.
- `/demo/settings` — профиль, анализ, уведомления, тариф. Настройки сохраняются в браузере.

Общая оболочка сохраняется при переключении вкладок. Мобильная версия имеет нижнюю навигацию. AI-ассистент в панели показывает заранее подготовленное объяснение демо-данных; внешних AI-запросов нет.

## Данные и оформление

`frontend/components/reference/demo-data.ts` — единый набор данных: 342 692 ₽ расходов, 1 248 конверсий, CPA 275 ₽ после округления, 1 892 430 ₽ выручки за семь дней. Трёхдневный период вычисляется из того же ряда. Таблица на главной распределяет расходы и конверсии с сохранением точной общей суммы. Эффект использует явный демонстрационный базовый период; проценты вычисляются из сумм.

Цвета и пропорции, панели, границы и градиенты взяты из референса. SVG-графики интерактивны: период, показатель, дата/значение, выбор точки и клавиатурное управление. Анимация страниц привязана к маршруту, а не к фильтру. `prefers-reduced-motion` отключает анимации и плавную прокрутку. Модальные окна используют нативный `dialog` с управлением фокусом и Escape.

## Декоративные изображения

Созданы встроенным imagegen, сохранены в проекте:

- `frontend/public/reference/glass-sculpture.png` — прозрачная иридисцентная стеклянная форма главной.
- `frontend/public/reference/glass-orb.png` — прозрачный стеклянный объект входа и подключения.

Промпт первого объекта: воспроизвести только стеклянную скульптуру верхнего левого экрана референса; гладкая органическая округлая треугольная петля из прозрачного синего стекла, голубой левый край, фиолетовый верхний правый край, розово-персиковые блики; полный объект на прозрачном фоне; убрать весь текст, интерфейс, карточки и фон, без длинного хвоста.

Промпт второго объекта: воспроизвести только объект экрана входа; мягкая округлая стеклянная капля синего и фиолетового цвета, позади справа вытянутый овал с розово-персиковыми бликами; прозрачный фон; без полых колец, хвоста, текста и элементов интерфейса.

Точная исходная геометрия этих растровых объектов недоступна. Изображения пересозданы по референсу, поэтому попиксельная идентичность не заявляется. Экран эффекта и некоторые раскрытые состояния созданы в той же визуальной системе, поскольку их точный оригинал не показан.

## Проверка

Браузерный сценарий: `frontend/scripts/check-reference.mjs`. Скриншоты отдельных страниц: `artifacts/reference-check/`, размеры 1536 × 1024 и 390 × 844. Проверяются навигация, формы, графики, решения по рекомендациям, подключения, настройки и отсутствие горизонтального переполнения.

Финальный проход выполнен на production-сборке: 8 страниц × 2 размера, 16 скриншотов, ошибок JavaScript нет. Проверены обязательные поля и минимальная длина пароля, показ/скрытие, сохранение и удаление только email, фильтры и решения, клавиатура графика, Escape в AI-окне, сохранение настроек после перезагрузки. Проверены выключенные анимации в reduced motion и переход 240 мс в обычном режиме; изменение фильтра сохраняет основной контейнер страницы.

`npm run build`, TypeScript и ESLint затронутых файлов прошли. `npm run test:headers` прошёл для 9 маршрутов и статического ресурса; браузерные проверки главной и кабинета показали 0 нарушений CSP и 0 ошибок консоли.

После первой визуальной сверки исправлены вложенные рамки полей, высота экрана входа и положение стеклянных объектов. Также исправлены шкалы графиков и согласованность чисел.

Отдельная финальная сверка мобильной главной выявила перекрытие CTA плавающими карточками. На мобильном карточки переведены в обычный поток после кнопок; в браузерный сценарий добавлены проверка непересечения блоков, доступности кнопок через hit testing и реальные переходы в регистрацию и демо.

Локальный просмотр: `http://127.0.0.1:3110`. Запуск из `frontend`: `npm run build`, затем `npm run start -- --hostname 127.0.0.1 --port 3110`.

Реальная авторизация по email, оплата, отправка уведомлений, внешние AI-запросы и изменения рекламы не подключены. Их отсутствие явно объясняется в интерфейсе.
