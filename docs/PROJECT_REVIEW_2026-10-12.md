# Проверка проекта AdPilot — 12 октября 2026

Проверка выполнена тремя агентами и основным агентом. Существующие незавершённые изменения сохранены. Внешние сервисы и production не изменялись.

## Внесённые исправления сайта

| Проблема | Изменение | Проверка |
|---|---|---|
| Настройки демо терялись после перезагрузки | Сохранение и сброс в localStorage, проверка имени/email/CPA, обработка ошибок хранилища, мобильная навигация | Assert-проверки и браузер: изменённые имя и переключатель восстанавливаются после reload; сброс работает |
| Кнопка кампании теряла выбранный ID | Ссылка передаёт campaign в рекомендации; доступное название содержит кампанию | Браузер: campaign=51234567 показывает одну рекомендацию выбранной кампании |
| CSV не экранировал названия и терял копейки | Кавычки, разделители, переносы строк, BOM, русские десятичные суммы, защита формул таблиц | Assert-проверки и реальная загрузка CSV браузером |
| Графики создавали NaN/Infinity при одном дне или пустой выборке | Безопасные координаты и явное состояние недостаточных данных; обработка нулей и несовпадающих массивов | Серверный рендер React: пустые, одиночные, нулевые и некорректные данные |
| Поиск не содержал новые разделы и не удерживал фокус | Добавлены анализ, кампании, AI-помощник, эффект, отчёты и тарифы; native dialog; сохранён возврат вложенного поиска по Esc | Браузер: вложенный Esc возвращает к командам; поиск «Отчёты» открывает страницу |

Изменения настроек действуют только на странице демо. Они не меняют реальные профили, правила аудита и отправку уведомлений.

## Результаты проверок

- `npm run build`: успешно, включая TypeScript и генерацию страниц.
- `npm run lint`: успешно.
- `npm run test:ui`: 3 файла проверок, все проходят.
- `npm run test:runtime`: успешно (CSP, backend origin, ошибки API, same-origin credentials).
- Браузер: сохранение/reload/reset настроек, вложенный Esc, поиск раздела, скачивание CSV, рекомендации выбранной кампании.
- Node выдаёт предупреждение MODULE_TYPELESS_PACKAGE_JSON для прямого импорта TypeScript в тесте; проверки проходят. Тип модулей всего приложения ради этого не менялся.

## Критический существующий блокер API

Импорт приложения подтверждённо завершается ошибкой `ModuleNotFoundError: No module named 'app.api.agents'`.

`backend/app/api/app.py` импортирует пять отсутствующих модулей:

- `backend/app/api/agents.py`
- `backend/app/api/recommendation_detail.py`
- `backend/app/api/auth_routes.py`
- `backend/app/api/onboarding_routes.py`
- `backend/app/api/integration_routes.py`

Проверка воспроизводится из backend:

```powershell
.\.venv\Scripts\python.exe -c "from app.api import create_app; print('API import OK')"
```

Текущие ответы `/me` и `/today` в существующем исходном коде соответствуют типам фронтенда. Это не устраняет ошибку импорта приложения.
