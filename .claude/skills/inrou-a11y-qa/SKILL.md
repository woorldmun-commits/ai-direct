---
name: inrou-a11y-qa
description: Use when reviewing INROU UI for accessibility - keyboard, focus, contrast, screen reader labels, mobile, reduced motion.
---

1. Клавиатура: весь сценарий (вход → подключение Директа → рекомендация → решение) проходится без мыши; порядок Tab логичен, нет ловушек фокуса, Esc закрывает модалки.
2. Фокус виден на всех интерактивных элементах в обеих темах.
3. Контраст WCAG AA: текст 4.5:1, крупный и иконки 3:1. Цвет не единственный носитель смысла (статусы «факт / оценка / нет данных» имеют текст).
4. Формы: label связан с полем, ошибки озвучиваются (`aria-live`/`aria-describedby`), понятные сообщения по-русски.
5. Графики: текстовая альтернатива или таблица с теми же числами.
6. `prefers-reduced-motion` отключает анимации; тап-цели ≥ 44 px на 375 px.
7. Автопроверка axe-core (Playwright) + ручной проход; отчёт: нарушение, место, как исправить.
